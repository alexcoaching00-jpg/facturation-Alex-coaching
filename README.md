# Alex Coaching — Factures

Application de facturation prête à publier sur GitHub Pages. Elle garde les clients et factures dans le navigateur, calcule le TTC instantanément selon le régime de TVA sélectionné et génère un aperçu imprimable en PDF.

## Mise en ligne GitHub

Dans un dépôt GitHub, chargez `index.html`, `styles.css`, `app.js` et `alex-coaching-logo.jpeg`. Puis ouvrez **Settings → Pages**, sélectionnez **Deploy from a branch**, la branche **main** et le dossier **/(root)**.

Avant l’envoi d’une facture réelle, renseignez les coordonnées, le SIRET et le régime TVA dans « Mon activité ».
